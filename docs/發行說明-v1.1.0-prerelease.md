## 本次更新

### 字型縮放

- 站台瀏覽頁標題列新增縮小／放大字型圖示按鈕
- 支援 50%～200%，每次調整 10%
- 到達上下限時自動停用對應按鈕
- 字型倍率全域保存，重新開啟 App 後仍會保留

### 首頁介面

- 站台卡片改用較淡的主題色底色，跟隨主題設定與深色模式
- 新增站台按鈕從右下角移至右上角工具列
- 更新空清單提示文字

## 完整功能

### 站台管理

- 新增、編輯、刪除站台
- 首頁站台清單
- 名稱／網址即時搜尋
- 長按拖曳排序，順序自動保存

### App 內瀏覽

- 點擊站台以 WebView 開啟
- 52dp 精簡標題列，最大化瀏覽空間
- 左上箭頭回到站台清單
- Android 返回鍵先回網頁上一頁，沒有歷史才回清單
- 載入進度、錯誤提示與重試
- 外部 scheme 交由系統處理
- 檔案下載支援

### 備份

- 匯出所有站台為 JSON
- 匯入 JSON 並取代現有站台
- 使用系統 SAF，不需要儲存權限

### 個人化

- 顯示模式：系統（預設）／淺色／深色
- 6 種活潑主題色
- Hue 彩色滑桿自訂主題色
- 主題色與顯示模式立即套用
- 狀態列與導覽列圖示跟隨主題

### App 圖示

- 地球儀圖案
- 粗線條卡通風格
- 天空藍球體、深藍外框與經緯線
- 支援 Android 13+ 主題圖示（monochrome）
- 核心圖案 56dp（66dp 安全區的 85%）

## 安裝方式

1. 下載 `app-prerelease.apk`。
2. 在 Android 裝置上允許安裝未知來源的應用程式。
3. 安裝並啟動「我的站台」。

若裝置已安裝不同簽署金鑰的版本，可能需要先解除安裝。

## 已知限制

- 此為 Pre-release 版本，使用 Debug 金鑰簽署，不是正式上線版本。
- 尚未在實機或模擬器上完成完整瀏覽與視覺驗證。
- 部分網站可能阻擋 WebView、要求特定瀏覽器或限制第三方登入。
- 自簽憑證或憑證錯誤的網站不會被載入。
- 允許 `http://` 站台，連線未加密，請注意風險。
- 匯入會取代目前所有站台，不支援合併。
- 尚未提供分類、我的最愛、密碼保護或雲端同步。

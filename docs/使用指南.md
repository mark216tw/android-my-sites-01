# 使用指南

本文說明「我的站台」的安裝、日常操作、設定與備份方式。

## 1. 安裝

### 1.1 安裝 Pre-release APK

1. 前往 [v1.4.0-prerelease 發行頁](https://github.com/mark216tw/android-my-sites-01/releases/tag/v1.4.0-prerelease)。
2. 下載 `app-prerelease.apk`。
3. 在 Android 裝置上開啟 APK，依系統提示允許「安裝未知來源的應用程式」。
4. 完成安裝後，從桌面啟動「我的站台」。

> 此 APK 使用 Debug 金鑰簽署並啟用 R8 壓縮，是測試版本，不是正式上線版本。若裝置已安裝其他簽署金鑰的版本，可能需要先解除安裝。

### 1.2 從原始碼建置

請參考 [建置與發行指南](建置與發行指南.md)。最簡短的方式：

```powershell
.\gradlew.bat :app:assembleDebug
```

產出：`app/build/outputs/apk/debug/app-debug.apk`

## 2. 首次啟動

首次開啟時，首頁會顯示「尚未新增站台」。點擊右上角的 **+** 開始新增第一個站台。

App 不需要註冊帳號，也不會連線到任何自有伺服器。站台清單保存在裝置本機。

之後重新開啟 App 時，會自動回到上次瀏覽的站台；若上次已經回到首頁，則會顯示首頁清單。

## 3. 首頁操作

### 3.1 新增站台

1. 點擊右上角 **+**。
2. 輸入「名稱」。
3. 輸入「網址」。
   - 可以只輸入 `example.com`，App 會自動補上 `https://`。
   - 也支援 `http://`、`localhost:8080`、IP 位址與中文網域。
4. 視需要點擊「選擇標籤」，勾選一個或多個標籤。
5. 點擊「儲存」。

名稱不可空白；網址必須是有效的 `http` 或 `https` 網址。

### 3.2 搜尋、篩選與排序

首頁上方的搜尋列會即時過濾站台名稱與網址。點擊右側清除圖示可恢復完整清單。

搜尋列下方的篩選列可切換：

- **全部**：顯示所有站台。
- **最愛**：只顯示已加入最愛的站台。
- **各標籤**：只顯示含有該標籤的站台。

搜尋列右側的排序圖示可選擇：

- 自訂順序
- 名稱 A→Z／Z→A
- 最近使用（新→舊／舊→新）
- 加入時間（新→舊／舊→新）

排序選擇會保存在裝置上。搜尋或使用非「自訂順序」時會隱藏拖曳把手，避免在過濾或排序後的清單中誤移動項目。

### 3.3 開啟站台

點擊站台卡片，即可在 App 內開啟該網站。App 會記住最後開啟的站台，下次啟動時直接回到該站台。

### 3.4 編輯、刪除與最愛

點擊站台右側的「更多」圖示：

- **編輯**：修改名稱、網址或標籤。
- **刪除**：確認後刪除站台。刪除不會影響網站本身。

點擊站台卡片右側的星號可加入或移除最愛；實心星號代表目前已加入最愛。

### 3.5 拖曳排序

1. 長按站台左側的拖曳把手。
2. 上下拖曳到想要的位置。
3. 放開後順序會自動保存。

排序會在稍後寫入本機檔案；離開 App 時也會強制保存。拖曳排序只在篩選「全部」、搜尋空白且排序為「自訂順序」時可用。

### 3.6 匯入與匯出

首頁右上角的 **⋮** 選單提供：

- **匯入 JSON**（上傳圖示）
- **匯出 JSON**（下載圖示）
- **設定**（齒輪圖示）

詳見第 6 節。

### 3.7 標籤管理

可從以下位置開啟標籤管理：

- 站台編輯中的「選擇標籤」→「管理標籤」
- 設定頁的「標籤管理」

可執行：

- **新增標籤**：輸入名稱並從 16 種顏色中選擇。
- **編輯標籤**：修改名稱或顏色。
- **刪除標籤**：確認後刪除，並從所有站台移除該標籤。
- **自訂排序**：長按左側拖曳把手調整標籤順序。

標籤名稱不可空白，也不可與現有標籤重複。

## 4. 站台瀏覽頁

### 4.1 標題列

站台頁頂部會顯示：

- 左側 **←** 返回箭頭
- 站台名稱（可點擊回到站台設定的網址）
- 右側 **A−／A+** 字型縮小／放大按鈕
- A+ 右側的 **重新載入** 按鈕

為了讓網站有最大的顯示空間，標題列只有 52dp 高，下方直接接 WebView。

字型倍率範圍為 50%～200%，每次調整 10%，到達上下限時對應按鈕會停用。**每個站台會各自保存自己的倍率**，切換到其他站台時會套用該站台自己的設定，重新開啟 App 後也會保留。

點擊重新載入按鈕會重載目前網頁；若目前顯示錯誤畫面，也會一併清除錯誤並重新載入。

### 4.2 返回行為

- 點擊左上角 **←**：固定回到站台清單。
- 按下 Android 系統返回鍵：
  1. 如果 WebView 還有上一頁，先回到網頁上一頁。
  2. 如果沒有上一頁，回到站台清單。

回到站台清單後會清除「上次站台」紀錄，因此下次啟動 App 會顯示首頁。

### 4.3 接續上次網址

- 離開站台時（按返回鍵回到清單，或 App 切到背景／關閉螢幕）會記住目前瀏覽的網址。
- 30 分鐘內再次開啟同一站台，會直接載入記住的網址；超過 30 分鐘則回到站台設定的網址。
- 點擊標題列的站台名稱，可立即回到站台設定的網址。
- 刪除站台、修改站台網址或匯入備份時，會清除記住的網址。
- 記住的網址只保存在本機，不會包含在 JSON 匯出中。

### 4.4 載入狀態與錯誤

- 載入時會顯示細長進度條。
- 若主要頁面載入失敗，會顯示錯誤畫面與「重試」按鈕。
- SSL 憑證錯誤不會被略過，會直接顯示錯誤，避免不安全連線。

### 4.5 外部連結與下載

- `http` / `https` 連結會留在 App 內的 WebView。
- 其他 scheme（例如 `mailto:`、`tel:`）會交給系統或其他 App 處理。
- `target="_blank"` 或 `window.open()` 會盡量在同一個 WebView 中開啟。
- 檔案下載會交給 Android 的 DownloadManager：
  - Android 10 以上：儲存到系統「下載」資料夾。
  - Android 8～9：儲存到 App 專屬外部下載資料夾。

## 5. 設定

點擊首頁右上角 **⋮** 選單中的「設定」進入設定頁。設定頁左上角 **←** 或 Android 返回鍵都會回到首頁。

### 5.1 顯示模式

提供三種選項：

- **系統**（預設）：跟隨 Android 系統的深色／淺色設定。
- **淺色**：固定使用淺色介面。
- **深色**：固定使用深色介面。

切換後立即套用。Android 狀態列與導覽列的圖示顏色也會跟著變成適合淺色或深色的樣式。

### 5.2 主題色彩

提供 6 個活潑的預設色彩：

| 名稱 | 色相 |
| --- | --- |
| 珊瑚紅 | 8° |
| 陽光橘 | 40° |
| 活力綠 | 95° |
| 薄荷綠 | 165° |
| 天空藍 | 215°（預設） |
| 葡萄紫 | 285° |

點擊圓形色塊即可立即切換主題色。選取中的色塊會顯示外環。

### 5.3 自訂 Hue 色彩

預設色塊下方有一個 Hue 彩色滑桿：

- 左側圓形色塊顯示目前自訂色彩。
- 拖曳滑桿可選擇 0°～360° 的色相。
- 拖曳時主題色會即時更新。
- 放開滑桿後才會寫入設定檔，避免高頻寫檔。
- 下方會顯示目前色彩名稱，例如「目前色彩：天空藍」或「目前色彩：自訂色彩」。

### 5.4 設定保存

顯示模式與主題色會保存在 App 的 SharedPreferences 中，重新啟動 App 後仍會保留。

## 6. JSON 匯出與匯入

### 6.1 匯出

1. 首頁右上角 **⋮** 選單點擊「匯出 JSON」。
2. 系統會開啟檔案儲存位置選擇器。
3. 預設檔名為 `my-sites-YYYY-MM-DD.json`。
4. 選擇位置後完成匯出。

匯出格式範例：

```json
{
  "version": 2,
  "exportedAt": "2026-11-02T12:00:00Z",
  "sites": [
    {
      "id": "0b0c...",
      "name": "範例網站",
      "url": "https://example.com",
      "createdAt": 1760000000000,
      "textZoom": 100,
      "favorite": true,
      "lastUsedAt": 1760000005000,
      "tagIds": ["tag-work"]
    }
  ],
  "tags": [
    {
      "id": "tag-work",
      "name": "工作",
      "colorIndex": 3
    }
  ]
}
```

### 6.2 匯入

1. 首頁右上角 **⋮** 選單點擊「匯入 JSON」。
2. 選擇 JSON 檔案。
3. App 會解析檔案並顯示確認訊息：
   - 將以匯入的站台數量取代目前所有站台。
4. 確認後完成匯入。

匯入規則：

- 支援標準備份格式，也支援直接以陣列包裝的站台清單。
- 舊版 version 1 備份仍可匯入；缺少的標籤、最愛與最近使用會使用預設值。
- 名稱空白或網址無效的站台會被忽略。
- 重複的站台或標籤 `id` 只保留第一筆。
- 缺少 `id` 的站台或標籤會自動產生新的 ID。
- 站台指向不存在的標籤時，該關聯會被移除。
- 顏色索引會夾在 0～15。
- 匯入會**取代**目前站台與標籤，不會合併。

### 6.3 備份建議

- 定期匯出 JSON 並保存到雲端或電腦。
- 解除安裝 App 會清除本機站台資料，請先匯出備份。

## 7. 資料與隱私

- 站台資料：`/data/data/com.example.mysites/files/sites.json`（App 內部儲存空間）
- 設定資料：App 的 SharedPreferences（`settings`）
- App 僅宣告 `INTERNET` 權限。
- 匯出／匯入透過系統 SAF，不需要讀寫儲存空間權限。
- App 不含分析、廣告或追蹤 SDK。
- WebView 關閉檔案存取與內容存取，不略過 SSL 錯誤。
- 為了支援區域網路或自訂 `http://` 站台，App 允許 cleartext traffic；請避免在不信任的網路環境輸入敏感資料。

## 8. 常見問題

### 8.1 網站載入失敗

可能原因：

- 裝置沒有網路連線。
- 網站阻擋 WebView 或要求特定瀏覽器。
- 網站憑證錯誤或已過期。
- 網站使用不支援的登入流程（例如部分 OAuth 或 App 內瀏覽器限制）。

可先點擊「重試」，或改用系統瀏覽器確認網站是否正常。

### 8.2 需要登入的網站無法使用

部分網站會偵測 WebView 或限制第三方 Cookie。App 已啟用 JavaScript、DOM Storage 與第三方 Cookie，但仍可能因網站政策而失敗。

### 8.3 出現憑證錯誤

App 不會略過 SSL 錯誤。若網站憑證過期、名稱不符或為自簽憑證，請聯絡網站管理者，或確認是否為可信任的內部服務。

### 8.4 為什麼可以輸入 `http://`？

為了支援區域網路設備（例如 NAS、路由器管理頁面）與尚未啟用 HTTPS 的站台。使用 `http://` 時資料未加密，請自行評估風險。

### 8.5 下載的檔案在哪裡？

- Android 10 以上：系統「下載」資料夾。
- Android 8～9：App 專屬外部資料夾，通常位於 `Android/data/com.example.mysites/files/Download/`。

### 8.6 更新 App 後資料會保留嗎？

只要使用相同簽署金鑰覆蓋安裝，站台與設定資料會保留。若簽署金鑰不同，Android 會要求先解除安裝，資料也會被清除，請先備份。

### 8.7 主題色沒有套用到系統列？

App 會設定狀態列與導覽列的圖示明暗樣式。部分 Android 版本或廠牌 UI 可能仍會加上系統預設的導覽列底色或對比陰影；這是系統行為。

### 8.8 App 圖示沒有立即更新？

部分桌面啟動器會快取圖示。可嘗試重新啟動啟動器、重新開機，或重新安裝 App。

### 8.9 重新開啟 App 時為什麼先看到載入畫面？

App 需要先讀取站台資料，才能顯示上次站台的標題與字型設定。載入期間會顯示簡短的載入指示，資料就緒後標題列與網頁會一起出現，避免只有網頁先顯示、標題卻空白的情況。

## 9. 解除安裝

解除安裝 App 會刪除：

- 站台清單
- 標籤、最愛與最近使用紀錄
- 顯示模式、主題色彩與排序設定
- WebView 相關本機資料

建議解除安裝前先匯出 JSON 備份。

## 本次更新

### 簡化的首頁工具列

- 右上角新增更多（⋮）選單
- 匯入 JSON、匯出 JSON 與設定收合到選單中
- 只保留新增站台（＋）與更多（⋮）兩個按鈕

### 站台標籤

- 每個站台可選擇多個標籤
- 標籤可設定名稱與 16 種顏色
- 標籤可新增、編輯、刪除，並可拖曳自訂排序
- 刪除標籤時會同步從站台移除該標籤

### 站台最愛

- 站台卡片可加入／移除最愛
- 實心星號代表已加入最愛

### 首頁篩選

- 可切換「全部」、「最愛」與各標籤
- 篩選時搭配搜尋可精確找到站台

### 首頁排序

- 搜尋列右側新增排序選單
- 支援自訂順序、名稱 A→Z／Z→A、最近使用（新→舊／舊→新）、加入時間（新→舊／舊→新）
- 排序選擇會保存在裝置上

### JSON 備份

- 備份格式提升為 version 2，包含標籤、最愛、最近使用與站台標籤關聯
- 舊版備份仍可正常匯入

## 完整功能

### 站台管理

- 新增、編輯、刪除站台
- 首頁站台清單
- 名稱／網址即時搜尋
- 拖曳排序（自訂順序），順序自動保存
- 多標籤管理：名稱、16 色、拖曳排序、CRUD
- 站台最愛

### App 內瀏覽

- 點擊站台以 WebView 開啟
- 52dp 精簡標題列，最大化瀏覽空間
- 每個站台各自記住字型倍率
- 放大字型按鈕右側提供重新載入按鈕
- 左上箭頭回到站台清單
- Android 返回鍵先回網頁上一頁，沒有歷史才回清單
- 載入進度、錯誤提示與重試
- 外部 scheme 交由系統處理
- 檔案下載支援

### 備份

- 匯出所有站台與標籤為 JSON（含最愛與最近使用）
- 匯入 JSON 並取代現有站台與標籤
- 使用系統 SAF，不需要儲存權限

### 個人化

- 顯示模式：系統（預設）／淺色／深色
- 6 種活潑主題色
- Hue 彩色滑桿自訂主題色
- 主題色與顯示模式立即套用
- 狀態列與導覽列圖示跟隨主題

### App 圖示

- 地球儀圖案
- 粗線條卡通風格
- 天空藍球體、深藍外框與經緯線
- 支援 Android 13+ 主題圖示（monochrome）

## 安裝方式

1. 下載 [`app-prerelease.apk`](https://github.com/mark216tw/android-my-sites-01/releases/download/v1.3.0-prerelease/app-prerelease.apk)。
2. 在 Android 裝置上允許安裝未知來源的應用程式。
3. 安裝並啟動「我的站台」。

若裝置已安裝不同簽署金鑰的版本，可能需要先解除安裝。

## 已知限制

- WebView 內的瀏覽歷史不會跨 App 重啟還原，只會回到站台的首頁網址。
- 部分網站可能阻擋 WebView、要求特定瀏覽器或限制第三方登入。
- 自簽憑證或憑證錯誤的網站不會被載入。
- 允許 `http://` 站台，連線未加密，請注意風險。
- 匯入會取代目前所有站台與標籤，不支援合併。
- 標籤管理與拖曳排序尚未在實機或模擬器完成驗證。
